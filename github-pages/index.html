GitHubとVSCodeでホームページを作って公開しよう

ソースコード共有サイトのGitHubに登録して、グループを作って、プログラミングするソフトのVSCodeをインストールして自分のホームページを公開しましょう。

完成するとこんなアドレスでホームページが公開されます。

https://kinoatj.github.io/github-pages-test/

https://（グループの名前）.github.io/（作ったフォルダの名前）/

GitHubでのホームページの公開には３つの道具を使います。

道具何をするもの
VSCode自分のパソコンで、コードを書くソフト
Gitソースコードの履歴を管理するソフト
GitHubインターネット上にコードを置いておく場所

全体の流れはこんなかんじ

VSCodeで書く　→　Gitで記録する　→　GitHubに送る　→　GitHubがホームページとして公開する

自分のパソコンでコードを書いて、GitHubに送る。これをくり返すのが、プログラマーの毎日の作業です。

目次
  1. GitHubにアカウントを作る
  2. グループ（Organization）を作る
  3. ホームページの置き場所（リポジトリ）を作る
  4. VSCodeとGitをインストールする
  5. GitHubのフォルダを自分のパソコンに持ってくる（クローン）
  6. ホームページの中身を書く
  7. 書いたものをGitHubに送る
  8. GitHub Pagesで世界に公開する
  9. 直して、更新する

STEP 1：GitHubにアカウントを作る

やること

  1. Chromeで https://github.com/ を開く
  2. 右上の Sign up をクリック
  3. Continue with Google をクリック
  4. Googleでアカウントを選択
  5. Usernameを決める（日本語は使えない）
  6. Create Account をクリック

STEP 2：グループ（Organization）を作る

GitHubには、Organizationというグループの機能があります。
チームで1つのものを作るとき、「個人のもの」ではなく「チームのもの」として置いておける場所です。

やること

  1. GitHubにログインした状態で、右上の丸いアイコンをクリック
  2. Settings を選ぶ
  3. 左のメニューの「Access」というかたまりの中の Organizations をクリック
  4. 「Organizations」の見出しの横にある New organization をクリック
  5. 無料のプラン（Free）を選ぶ
  6. グループの名前とメールアドレスを入力する
  7. ここで友達を招待することもできる

友達をグループに入れる

  1. 作ったグループのページを開く
  2. 上のタブの People をクリック
  3. Invite member をクリックして、相手のUsernameかメールアドレスを入力

招待された人が承認すると、メンバーになります。

STEP 3：ホームページの置き場所（リポジトリ）を作る

いよいよホームページ用のフォルダを作ります。

やること

  1. グループのページを開く
  2. New repository（緑色のボタン、または「Repositories」タブの中）をクリック
  3. 次のように入れる
    • Repository name：kino-homepage（好きな名前でOK。半角英数とハイフンだけにしてください）
    • Description：はじめてのホームページ（空でもOK）
    • Public / Private：Public を選ぶ
    • Add a README file：チェックを入れる
  4. Create repository をクリック
なぜPublicなの？

Public（公開）は「中身が誰でも見られる」という意味です。ちょっと不安に感じるかもしれませんが、無料プランでホームページを公開するにはPublicが必要です。

つまり、書いたコードも全世界に見えます。だからこそ、パスワードや個人情報をコードの中に絶対に書かないでください。

これで、インターネット側の準備は完了です。ここから自分のパソコン側を用意します。

STEP 4：VSCodeとGitをインストールする

4-1. Gitをインストールする

VSCodeだけでは、GitHubにファイルを送れません。裏で動くGitが必要です。

  1. https://git-scm.com/install/windows を開く
  2. 「Git for Windows/x64 Setup」をクリックしてダウンロード
  3. ダウンロードした .exe ファイルをダブルクリック
  4. インストール画面がたくさん出てきますが、すべて「Next」を押していけばOKです。最後に「Install」を押します
選択肢が多すぎて不安になるところ

Gitのインストーラは、ふだん見ないような英語の選択肢を10画面くらい出してきます。全部そのままで問題ありません。ここは深く考えずに進んでください。

4-2. VSCodeをインストールする

  1. https://code.visualstudio.com/ を開く
  2. Download for Windows をクリック
  3. ダブルクリックして、案内にしたがって進める

4-3. VSCodeを日本語にする

初めて起動すると英語です。日本語にしましょう。

  1. 左端のアイコンが並んだ列（アクティビティバー）で、四角が4つ並んだアイコン（拡張機能 / Extensions）をクリック
  2. 検索ボックスに Japanese と入力
  3. 「Japanese Language Pack for Visual Studio Code」の Install をクリック
  4. 右下に「再起動しますか？」と出るので Change Language and Restart をクリック

日本語になりました。ここから先の説明は日本語表示を前提にします。

4-4. 自分の名前をGitに教える

Gitは「誰がこの記録を作ったか」を残します。最初に1回だけ設定します。

  1. VSCodeのメニューから ターミナル → 新しいターミナル を開く
  2. 下に出てきた黒い画面に、次の2行を1行ずつ貼り付けて Enter
git config --global user.name "あなたのGitHubのUsername"
git config --global user.email "あなたのメールアドレス"
メールアドレスを公開したくない場合

ここに書いたメールアドレスは、GitHub上の記録に残って他の人からも見えます。隠したい場合は、GitHubの Settings → Emails で「Keep my email addresses private」にチェックを入れると、〇〇@users.noreply.github.com という専用のアドレスがもらえます。そのアドレスを上のコマンドに使ってください。

STEP 5：GitHubのフォルダを自分のパソコンに持ってくる（クローン）

インターネット上にあるリポジトリを、自分のパソコンにコピーします。これをクローンと言います。

やること

  1. ブラウザでSTEP 3で作ったリポジトリのページを開く
  2. 緑色の Code ボタンをクリックし、表示されたURLの右のコピーアイコンを押す
    • https://github.com/……/homepage.git のようなURLです
  3. VSCodeに戻り、Ctrl + Shift + P を押す（上に細長い入力欄が出ます）
  4. Git: クローン と入力して Enter（まだ英語表示なら Git: Clone）
  5. コピーしたURLを貼り付けて Enter
  6. 「どこに保存する？」と聞かれるので、ドキュメント などわかる場所を選ぶ
  7. 「開きますか？」と出たら 開く をクリック

VSCodeの左側に README.md というファイルが1つ見えていれば成功です。
これで、パソコンとインターネットがつながりました。

つまずきポイント

  • Git: クローン が候補に出てこない → Gitがインストールできていません。STEP 4-1をやり直して、VSCodeを一度閉じて開き直してください
  • サインインを求められた → 「許可」を押すとブラウザが開きます。GitHubでログインして、戻ってきたVSCodeの画面で続けてOKです

STEP 6：ホームページの中身を書く

6-1. ファイルを作る

  1. VSCodeの左側（エクスプローラー）で、フォルダ名の横の新しいファイルアイコンをクリック
  2. ファイル名を index.html にして Enter
名前は必ず index.html

ウェブの世界では、index.html が「そのフォルダの表紙」という決まりになっています。Index.html や index.HTML、インデックス.html ではダメです。全部半角小文字で入れてください。

6-2. 中身を書く

下のコードを、まるごとコピーして貼り付けてください。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>はじめてのホームページ</title>
  <style>
    body {
      font-family: sans-serif;
      max-width: 640px;
      margin: 0 auto;
      padding: 32px 20px;
      line-height: 1.8;
      color: #222;
    }
    h1 {
      border-bottom: 3px solid #4a9;
      padding-bottom: 8px;
    }
    .card {
      background: #f4f7f6;
      border-radius: 10px;
      padding: 16px 20px;
      margin-top: 24px;
    }
  </style>
</head>
<body>
  <h1>はじめてのホームページ</h1>
  <p>これは自分で作って、自分で公開したページです。</p>

  <div class="card">
    <h2>好きなもの</h2>
    <ul>
      <li>ここに好きなものを書く</li>
      <li>もう1つ書く</li>
      <li>さらに書く</li>
    </ul>
  </div>

  <p>作った日：ここに今日の日付を書く</p>
</body>
</html>

貼り付けたら保存します。

6-3. 自分のパソコンで見てみる

ファイルを保存したら、まず自分の目で確認します。

  • エクスプローラー（VSCodeの左側）の index.html を右クリック → エクスプローラーで表示
  • 開いたフォルダの index.html をダブルクリック

ブラウザが開いて、さっき書いたページが表示されます。
この時点では、まだ自分のパソコンの中だけです。インターネットには出ていません。

6-4. 自分の言葉に書きかえる

ここが一番おもしろいところです。次を自由に変えてみてください。

  • <h1> の中の文字 → ページの大見出し
  • <li> の中の文字 → 箇条書きの1行。行を増やしても減らしてもOK
  • <title> の中の文字 → ブラウザのタブに出る名前
  • #4a9 の部分 → 線の色。#e57 や #59c などに変えると色が変わります
  • 「ここに今日の日付を書く」 → 実際の日付

変えたら保存して、ブラウザで F5（再読み込み）します。

STEP 7：書いたものをGitHubに送る

自分のパソコンで書いたファイルを、インターネット側に送ります。3ステップです。

やること

  1. VSCodeの左端のアイコン列で、枝が分かれたようなアイコン（ソース管理）をクリック
  2. 「変更」の中に index.html が出ています。ファイル名の上にマウスを乗せて、+ をクリック
    • → これがステージ。「今回送るのはこれです」と選ぶ作業です
  3. 上のメッセージ入力欄に、何をしたかを書く
    • 例：最初のページを作った
  4. コミット ボタンをクリック
    • → これがコミット。パソコンの中に「この時点の記録」が保存されます
  5. ボタンが 変更の同期 に変わるのでクリック
    • → これがプッシュ。GitHubに送られます

途中でGitHubへのサインインを求められたら、案内にしたがってブラウザでログインしてください。

この3つの意味をもう一度

作業何をしているたとえると
ステージ（+）送るファイルを選ぶ段ボールに入れる
コミット記録を作るガムテープで封をして、中身をメモする
同期（プッシュ）GitHubに送る宅配便に出す

ブラウザでGitHubのリポジトリを再読み込みしてみてください。index.html が増えていれば成功です。

STEP 8：GitHub Pagesで世界に公開する

ここまでで、ファイルはGitHubに置いてあります。でもまだ「ホームページ」にはなっていません。
最後に、公開のスイッチを入れます。

やること

  1. ブラウザでリポジトリのページを開く
  2. 上のタブの Settings をクリック
  3. 左のメニューの「Code, planning, and automation」の中の Pages をクリック
  4. 「Build and deployment」の Source で Deploy from a branch を選ぶ
  5. Branch のところで main を選び、フォルダは / (root) のまま
  6. Save をクリック

これで完了です。

URLを確認する

保存して少し待ってから、同じPagesの画面を再読み込みしてください。上のほうにURLが表示されます。

https://（グループの名前）.github.io/（作ったフォルダの名前）/
すぐには表示されません

公開の準備には数分（長いと10分ほど）かかります。開いて「404 Not Found」と出ても失敗ではありません。5分ほど待ってから、もう一度読み込んでください。

何度も試しても404のままなら、index.html というファイル名が正しいか（大文字が混ざっていないか）を確認してください。ここが原因の9割です。

表示されたら、そのURLを自分のスマホに送ってみてください。

STEP 9：直して、更新する

公開したあとの直し方も覚えておきましょう。これがふだんの作業です。

  1. VSCodeで index.html を直す
  2. ソース管理を開いて + → メッセージを書く → コミット → 変更の同期
  3. 数分待って、公開URLを再読み込み

この3ステップだけです。STEP 1〜5はもうやる必要がありません。
一度環境を作れば、あとはずっと「書く・送る」のくり返しになります。
