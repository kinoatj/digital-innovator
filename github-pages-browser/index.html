インストールなしでホームページを作って公開しよう
ブラウザだけ版

この手順書は、学校のパソコンなど、ソフトをインストールできない環境向けです。
必要なのはChromeとGoogleアカウントだけ。GitもVSCodeもパソコンに入れません。

そのかわりに、ブラウザの中で動くVSCode（github.dev）を使います。見た目も操作もふつうのVSCodeとほとんど同じなので、あとでインストールできる環境に移っても、覚えたことはそのまま使えます。

インストールできる人は

自分のパソコンにGitとVSCodeを入れられる人は、GitHubとVSCodeでホームページを作って公開しようのほうを読んでください。STEP 1〜3はどちらも同じです。

完成するとこんなアドレスでホームページが公開されます。

https://kinoatj.github.io/github-pages-test/

https://（グループの名前）.github.io/（作ったフォルダの名前）/

使う道具は３つ。全部ブラウザの中にあります。

道具何をするもの
Chromeブラウザ。すべての作業をこの中でやる
GitHubインターネット上にコードを置いておく場所
ブラウザ版VSCode（github.dev）ブラウザの中で動くVSCode。コードを書いて、GitHubに保存する

全体の流れはこんなかんじ

ブラウザ版VSCodeで書く　→　コミットしてGitHubに保存する　→　GitHubがホームページとして公開する

ふつうのやり方では「自分のパソコンで書く → Gitで記録 → GitHubに送る」の３段階ですが、ブラウザ版では最初からGitHubの上で書いているので、「送る」がありません。そのぶん手順が少なくてすみます。

目次
  1. GitHubにアカウントを作る
  2. グループ（Organization）を作る
  3. ホームページの置き場所（リポジトリ）を作る
  4. ブラウザでVSCodeを開く
  5. ホームページの中身を書く
  6. コミットしてGitHubに保存する
  7. GitHub Pagesで世界に公開する
  8. 直して、更新する
  9. おまけ：VSCodeを使わずGitHubの画面だけで書く方法
  10. おまけ：Gitはどこに行ったの？

STEP 1：GitHubにアカウントを作る

やること

  1. Chromeで https://github.com/ を開く
  2. 右上の Sign up をクリック
  3. Continue with Google をクリック
  4. Googleでアカウントを選択
  5. Usernameを決める（日本語は使えない）
  6. Create Account をクリック

STEP 2：グループ（Organization）を作る

GitHubには、Organizationというグループの機能があります。
チームで1つのものを作るとき、「個人のもの」ではなく「チームのもの」として置いておける場所です。

やること

  1. GitHubにログインした状態で、右上の丸いアイコンをクリック
  2. Settings を選ぶ
  3. 左のメニューの「Access」というかたまりの中の Organizations をクリック
  4. 「Organizations」の見出しの横にある New organization をクリック
  5. 無料のプラン（Free）を選ぶ
  6. グループの名前とメールアドレスを入力する
  7. ここで友達を招待することもできる

友達をグループに入れる

  1. 作ったグループのページを開く
  2. 上のタブの People をクリック
  3. Invite member をクリックして、相手のUsernameかメールアドレスを入力

招待された人が承認すると、メンバーになります。

STEP 3：ホームページの置き場所（リポジトリ）を作る

いよいよホームページ用のフォルダを作ります。

やること

  1. グループのページを開く
  2. New repository（緑色のボタン、または「Repositories」タブの中）をクリック
  3. 次のように入れる
    • Repository name：kino-homepage（好きな名前でOK。半角英数とハイフンだけにしてください）
    • Description：はじめてのホームページ（空でもOK）
    • Public / Private：Public を選ぶ
    • Add a README file：チェックを入れる
  4. Create repository をクリック
なぜPublicなの？

Public（公開）は「中身が誰でも見られる」という意味です。ちょっと不安に感じるかもしれませんが、無料プランでホームページを公開するにはPublicが必要です。

つまり、書いたコードも全世界に見えます。だからこそ、パスワードや個人情報をコードの中に絶対に書かないでください。

これで置き場所ができました。ふつうならここから「パソコンにソフトを入れる」のですが、この手順書ではそれをしません。次のSTEPでそのままブラウザの中に作業場所を開きます。

STEP 4：ブラウザでVSCodeを開く

GitHubには、リポジトリをそのままVSCodeで開く機能がついています。インストールはいりません。

やること

  1. ブラウザでSTEP 3で作ったリポジトリのページを開く
  2. ページのどこか（ファイル一覧のあたり）を1回クリックしてから、キーボードの .（ピリオド）を1回押す
  3. 画面が切りかわって、VSCodeが開く。左側にSTEP 3で作った README.md が見えていれば成功
ピリオドを押しても何も起きないとき

日本語入力がオンになっていると「。」が入力されてしまいます。半角英数に切りかえてからもう一度押してください。

それでもダメなら、アドレスバーのURLを書きかえる方法もあります。github.com の部分を github.dev に変えて Enter を押してください。

https://github.com/グループ名/kino-homepage
　　　　　↓
https://github.dev/グループ名/kino-homepage

はじめて開くときは「GitHubにサインインしますか？」「許可しますか？」のような確認が出ることがあります。案内にしたがって 許可 や Continue を押してください。

4-1. 日本語にする

初めて開くと英語です。ブラウザが日本語になっていれば、右下に「日本語に変更して再起動しますか？」という案内が出るので、そのボタン（Change Language and Restart）を押すだけで日本語になります。

案内が出なかったときは、ふつうのVSCodeと同じ手順でできます。

  1. 左端のアイコンが並んだ列（アクティビティバー）で、四角が4つ並んだアイコン（拡張機能 / Extensions）をクリック
  2. 検索ボックスに Japanese と入力
  3. 「Japanese Language Pack for Visual Studio Code」の Install をクリック
  4. 右下に出る Change Language and Restart をクリック

ここから先の説明は日本語表示を前提にします。もし日本語にできなくても、下の表で置きかえて読めば進められます。

日本語表示英語表示
エクスプローラーExplorer
新しいファイルNew File
ソース管理Source Control
変更Changes
コミットしてプッシュCommit & Push
名前の設定はいりません

ふつうのGitでは最初に「自分の名前とメールアドレス」を設定しますが、ブラウザ版はGitHubにログインした状態で動いているので、その設定はいりません。記録には自動であなたのGitHubの名前がつきます。

STEP 5：ホームページの中身を書く

5-1. ファイルを作る

  1. VSCodeの左側（エクスプローラー）で、フォルダ名の横の新しいファイルアイコンをクリック
  2. ファイル名を index.html にして Enter
名前は必ず index.html

ウェブの世界では、index.html が「そのフォルダの表紙」という決まりになっています。Index.html や index.HTML、インデックス.html ではダメです。全部半角小文字で入れてください。

5-2. 中身を書く

下のコードを、まるごとコピーして貼り付けてください。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>はじめてのホームページ</title>
  <style>
    body {
      font-family: sans-serif;
      max-width: 640px;
      margin: 0 auto;
      padding: 32px 20px;
      line-height: 1.8;
      color: #222;
    }
    h1 {
      border-bottom: 3px solid #4a9;
      padding-bottom: 8px;
    }
    .card {
      background: #f4f7f6;
      border-radius: 10px;
      padding: 16px 20px;
      margin-top: 24px;
    }
  </style>
</head>
<body>
  <h1>はじめてのホームページ</h1>
  <p>これは自分で作って、自分で公開したページです。</p>

  <div class="card">
    <h2>好きなもの</h2>
    <ul>
      <li>ここに好きなものを書く</li>
      <li>もう1つ書く</li>
      <li>さらに書く</li>
    </ul>
  </div>

  <p>作った日：ここに今日の日付を書く</p>
</body>
</html>

貼り付けたら Ctrl + S で保存します。

「保存」しただけでは、まだGitHubに入っていません

ブラウザ版VSCodeでの「保存」は、いま使っているブラウザの中に一時的にとっておくだけです。GitHubに入るのは、次のSTEP 6でコミットしたときです。

学校のパソコンは、電源を切ると中身が消える設定になっていることがあります。授業の終わりには必ずSTEP 6のコミットまでやってください。コミットしていない分は消えてしまうかもしれません。

5-3. 自分の言葉に書きかえる

ここが一番おもしろいところです。次を自由に変えてみてください。

  • <h1> の中の文字 → ページの大見出し
  • <li> の中の文字 → 箇条書きの1行。行を増やしても減らしてもOK
  • <title> の中の文字 → ブラウザのタブに出る名前
  • #4a9 の部分 → 線の色。#e57 や #59c などに変えると色が変わります
  • 「ここに今日の日付を書く」 → 実際の日付

5-4. 見た目を確認したいとき

ブラウザ版VSCodeは、パソコンの中にファイルを置いていないので、「ダブルクリックして開く」ができません。確認のしかたは２つあります。

  • 公開してから見る（おすすめ）：STEP 7まで進めて一度公開すると、あとはコミットするたびに1〜2分で公開ページが更新されます。ふだんはこれで十分です
  • 今すぐ見る：エクスプローラーの index.html を右クリック → ダウンロード。パソコンの「ダウンロード」フォルダに入ったファイルをダブルクリックすると、ブラウザで開けます。ただし、これは「そのときのコピー」なので、書きかえたらもう一度ダウンロードが必要です

STEP 6：コミットしてGitHubに保存する

書いたファイルを、GitHubに正式に記録します。

やること

  1. VSCodeの左端のアイコン列で、枝が分かれたようなアイコン（ソース管理）をクリック
  2. 「変更」の中に index.html が出ています。ファイル名の上にマウスを乗せて、+ をクリック
    • → これがステージ。「今回記録するのはこれです」と選ぶ作業です
  3. 上のメッセージ入力欄に、何をしたかを書く
    • 例：最初のページを作った
  4. コミットしてプッシュ ボタンをクリック
    • → これがコミット。「この時点の記録」がGitHubに保存されます

ボタンを押すと画面が一瞬読み込み直されて、「変更」の中が空になります。これで完了です。

ふつうのVSCodeとのちがい

作業ふつうのVSCodeブラウザ版VSCode
ステージ（+）送るファイルを選ぶ同じ
コミットパソコンの中に記録を作るGitHubに直接記録を作る
同期（プッシュ）GitHubに送るいらない。コミットと同時に終わっている

ブラウザでGitHubのリポジトリのページを開いてみてください。index.html が増えていれば成功です。
（アドレスバーの github.dev を github.com に戻すと、いつものリポジトリのページに戻れます）

つまずきポイント

  • コミットのボタンが押せない → メッセージが空です。何か書いてください
  • 「変更」に何も出てこない → まだファイルを保存していないか、書きかえがありません。Ctrl + S を押してみてください
  • 前回書いたものが見当たらない → コミットしないまま閉じた分は、そのパソコンのそのブラウザの中にしかありません。同じパソコンならソース管理の「変更」に残っていることがあります。別のパソコンからは見えないので、コミットしたところからやり直してください

STEP 7：GitHub Pagesで世界に公開する

ここまでで、ファイルはGitHubに置いてあります。でもまだ「ホームページ」にはなっていません。
最後に、公開のスイッチを入れます。

やること

  1. ブラウザでリポジトリのページ（github.com のほう）を開く
  2. 上のタブの Settings をクリック
  3. 左のメニューの「Code, planning, and automation」の中の Pages をクリック
  4. 「Build and deployment」の Source で Deploy from a branch を選ぶ
  5. Branch のところで main を選び、フォルダは / (root) のまま
  6. Save をクリック

これで完了です。

URLを確認する

保存して少し待ってから、同じPagesの画面を再読み込みしてください。上のほうにURLが表示されます。

https://（グループの名前）.github.io/（作ったフォルダの名前）/
すぐには表示されません

公開の準備には数分（長いと10分ほど）かかります。開いて「404 Not Found」と出ても失敗ではありません。5分ほど待ってから、もう一度読み込んでください。

何度も試しても404のままなら、index.html というファイル名が正しいか（大文字が混ざっていないか）を確認してください。ここが原因の9割です。

表示されたら、そのURLを自分のスマホに送ってみてください。

STEP 8：直して、更新する

公開したあとの直し方も覚えておきましょう。これがふだんの作業です。

  1. リポジトリのページで . を押して、ブラウザ版VSCodeを開く
  2. index.html を直して Ctrl + S
  3. ソース管理を開いて + → メッセージを書く → コミットしてプッシュ
  4. 1〜2分待って、公開URLを再読み込み

STEP 1〜3と7はもうやる必要がありません。
どのパソコンからでも、Chromeで GitHub にログインすれば、いつでも続きから作業できます。これがブラウザ版のいいところです。

おまけ：VSCodeを使わずGitHubの画面だけで書く方法

学校のネットワークで github.dev が開けないときや、もっとかんたんにすませたいときは、GitHubのページ上で直接ファイルを作ることもできます。

新しいファイルを作る

  1. リポジトリのページを開く
  2. 緑色の Code ボタンの左にある Add file → Create new file をクリック
  3. 上の入力欄にファイル名 index.html を入れる
  4. 大きな入力欄にSTEP 5のコードを貼り付ける
  5. 右上の Commit changes... をクリック
  6. 出てきた画面でもう一度 Commit changes をクリック

あるファイルを直す

  1. リポジトリのページで index.html をクリック
  2. 右上のえんぴつのアイコン（Edit this file）をクリック
  3. 直して、Commit changes... → Commit changes

やっていることはSTEP 6と同じ「コミット」です。ただ、色分けや入力の補助がないので、長いコードを書くならブラウザ版VSCodeのほうが楽です。

おまけ：Gitはどこに行ったの？

もう一方の手順書では、パソコンにGitというソフトを入れました。この手順書ではひとことも出てきません。でも、Gitがなくなったわけではありません。

GitはGitHubのサーバーの中で動いています。ふつうのやり方では「自分のパソコンのGit」と「GitHubのGit」の2か所に記録があって、その間をプッシュで運んでいました。ブラウザ版では、自分のパソコン側をなくして、GitHub側のGitに直接書きこんでいるのです。

ふつうのやり方ブラウザだけ版
コードを書く場所自分のパソコンブラウザ（github.dev）
記録（コミット）が作られる場所自分のパソコンGitHub
GitHubに送る（プッシュ）必要いらない
ネットがなくても作業できるできるできない
インストールGitとVSCodeなし

コミット、リポジトリ、GitHub Pagesといった言葉はどちらでも同じです。この手順書で覚えたことは、いつかインストールできるパソコンを手に入れたとき、そのまま役に立ちます。そのときはもう一方の手順書のSTEP 4から読んでください。
